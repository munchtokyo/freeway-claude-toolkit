## 1. 研修の目的

フリーウェイにおける **予約処理・顧客情報管理・前日連絡業務の DX** を、受講者自身が担えるようにするための AI スキル習得 (OFF-JT)。

「川島が代わりにやる」ではなく「受講者 3 名様が自分でできるようになる」が目的。

## 5. OFF-JT 厳守事項

- **本研修は OFF-JT** (企業活動とは区別して行われる訓練) として実施
- 講師による業務代行、本番予約処理、本番システムの開発・納品は**行わない**
- 演習はすべて**匿名化データまたは架空データ**を使用
- 成果物は受講者の技能習得の証跡 (本番システムそのものではない)

5/28-31 の 4 日間訪問は**契約外コンサル枠**で、上記制約に縛られない。本訪問で構築するものと、7 月以降の研修内容を**明確に切り分ける**。

---

## 6. 受講者習得目標 (修了時点)

修了後、3 名様が以下ができる状態:

1. Claude Code を起動して基本的な対話ができる
2. `/skill-creator` で自分用スキルを作れる
3. auto-memory が貯めた知見を `/self-improving-agent` で整理できる
4. マスト 5 選 (Playwright / Exa / Context7 / Repomix / Document Skills) を業務で使い分けられる
5. 業務改善のアイデアを Claude Code と対話して形にできる

**川島が居なくなっても自走できる状態**が修了基準。
