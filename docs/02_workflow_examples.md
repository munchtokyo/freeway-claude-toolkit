# 業務で使う具体例 (叩き台)

> ⚠️ **このドキュメントは叩き台です**。川島が**想像で書いた** 10 例で、フリーウェイの実業務とは違う可能性が高いです。
>
> ここに書いてあるコマンド名 (`/yoyaku-merge` 等) は **まだスキルとして実装されていません**。スキル本体は `/skill-creator` を使って皆様の体に馴染む名前・粒度で作っていく前提です。
>
> このファイルは「こういう使い方があり得る」のイメージ集として読んでください。実業務で「これは違う」「こうしたい」と気づいたら、書き換え・追加・削除してください。

---

## 1. 朝、HP 予約フォームからの新着予約を整理したい

```
/yoyaku-merge
今日入ってきたHP予約をスプレッドシートに反映して
```

→ Claude が既存 GAS 連携から取得済みの予約行をチェックし、抜けがあれば追記。重複あれば指摘。

---

## 2. 電話で入った予約をメモしたい

```
/yoyaku-merge
今、電話で田中さんから 6/15 体験コース 2名 リクエスト来た
ライセンスなし、初心者、特になし
```

→ Claude が「予約台帳」スプレッドシートに新規行を追加。必須項目チェック。

---

## 3. 個人 LINE で来た予約をスクショから取り込みたい

```
/yoyaku-merge
このスクショ、LINE の予約。スプレッドシートに入れて
```

（画像を貼り付け or `screenshots/` フォルダのファイルを指定）

→ Claude が画像を OCR して内容を構造化、スプレッドシートに追加。

---

## 4. じゃらんの CSV を取り込みたい

```
/yoyaku-merge
~/Downloads/jaran_7月.csv をスプレッドシートにマージして
```

→ Claude が CSV を読み、既存予約との重複を排除して追記。

---

## 5. 翌日のお客様への連絡を一気に作りたい

```
/zenjitsu-renraku
明日 6/15 の予約一覧を見て、お客様への連絡下書きを作って
```

→ Claude が:
- メール下書き（顧客別・集合場所・時間・持ち物・天候）
- LINE 下書き（個人携帯 LINE 用）
- 電話原稿（電話派の顧客用要点メモ）
- Google Calendar 反映
- を全部一括生成。**送信ボタンは押さない**。中身を確認してから人が送る。

---

## 6. ダイビング終了後、お客様の様子をメモしたい（音声）

```
/karte
今日の田中さん、最初緊張してたけどコブダイ見た瞬間目の色変わってた。
中性浮力はまだ安定しないけど次回もコブダイ系のポイントがいい。
あと安藤さんと相性良さそうだった。
次に来る時はもう少し深いポイントも提案できそう。
```

→ Claude が「顧客マスター」スプレッドシートの田中さん行に構造化して追記。
- 挙動: 「最初緊張型・コブダイで覚醒」
- 技術: 「中性浮力未安定」
- 講師相性: 「安藤と好相性」
- 次回提案: 「コブダイ系ポイント・もう少し深いところ可」

---

## 7. リピーターが帰ってくる時、過去の情報を一気に思い出したい

```
/karte
来週、田中さんが来る。過去履歴と注意点を全部出して
```

→ Claude が田中さんのカルテを読み、過去の挙動・好み・講師相性・注意事項を要約してくれる。
チーム分けや講師アサインの判断材料として使う。

---

## 8. 休業日をカレンダーに一気に登録したい

```
/kyugyo-calendar
8/1-8/31 を全部休業日として Google Calendar に入れて
```

→ Claude が Google Calendar API で休業日イベントを一括登録。

---

## 9. お客様の体型からスーツサイズの目安が欲しい

```
/kizai-match
明日の田中さん、身長170・体重65・男性。スーツとブーツのサイズ候補は？
```

→ Claude が過去履歴（同じ体型のお客様のサイズ）を参照しつつ、M/L 候補を提案。
**最終決定は人間**（着てみないと分からないから）。

---

## 10. 英語のお客様からのメールに返信したい

```
/tagengo-reply
これ英語のメール来た。 ~/Downloads/email.txt を読んで、日本語要約と返信ドラフトを英語で作って
```

→ Claude が要約 + 英語返信ドラフト生成。**送信はしない**。


## よく使う流れ（1 日のパターン）

```
朝 9:00   /yoyaku-merge で予約整理
朝 9:30   今日のチーム分け検討（Claude に過去カルテを聞きながら）
昼        ダイビング実施
夕 17:00  /karte で今日のお客様メモを記録
夕 17:30  /zenjitsu-renraku で翌日の連絡下書き作成
夕 18:00  下書きを確認して送信
```

これで 1 日の事務作業が 4-5 時間 → 2 時間ぐらいに圧縮できる、はず。
