# メール返信プレイブック（新潟店）

新潟店の PC 業務の大半を占めるメール返信を、Claude と一緒に楽にするための叩き台です。
2026-05-31 に矢吹さんから聞き取った実態をベースに作っています。
業務をしながら「うちはこうだ」と気づいたら、皆様の手で書き換えてください。

---

## このファイルの位置づけ

- ここに入っているのは「返信を**書くための材料とテンプレ**」です
- 送信ボタンは必ず人が押します（AI は下書きまで。`rules/no-auto-send.md`）
- お客様の実名・連絡先は貼り付けない、残さない（`rules/customer-data-handling.md`）
- 矢吹さんが埋めた本物の文面・好みが、こちらが正本

## 1. 新潟店メール返信の実態（矢吹さん 2026-05-31）

| 項目 | 実態 |
|---|---|
| 1 日の通数 | 2〜3 通、多くて 5 通 |
| 多い時間帯 | 夕方 |
| 一番多い内容 | 予約の問い合わせ、料金・コースの質問。**特にコース内容の説明が最多** |
| 必ず聞き返すこと | 人数 / 経験本数 / ブランクの有無 / レンタルの有無 |
| 新規への返信 | 丁寧に返す |
| 常連への返信 | 少しフレンドリーに返す |
| 外国のお客様 | あまり来ない。翻訳しながら返している |
| 一番の悩み | **丁寧に返信する語彙力がない。AI が丁寧に返してくれると助かる** |

### ここから分かること

通数は多くないが、**1 通あたりの「丁寧に書く負担」が大きい**のが新潟店の本質。
件数を減らす自動化より、**「丁寧な文章を書く部分を AI が肩代わりする」**のが一番効く。

## 2. 一番の願いへの答え：AI 下書き ＋ humanizer

矢吹さんの「丁寧な語彙力がない」をそのまま解決する流れがこれです。

```
1. お客様から来たメールを Claude に渡す（名前・連絡先は消す）
   または 返したい要点をラフに箇条書きで伝える
        ↓
2. Claude が「丁寧なメール返信の下書き」を作る
        ↓
3. /humanizer で AI っぽさを消して、人が書いた自然な丁寧文に整える
        ↓
4. 矢吹さんが目で確認・微調整
        ↓
5. Outlook で自分で送信
```

### 使い方の例（そのまま言えばいい）

- 「このお客様のメールに、丁寧に返信する下書きを作って」（メール本文を貼る）
- 「コース内容を説明する丁寧な返信を作って。人数と経験を聞き返す形で」
- 「この下書き、丁寧だけど少し硬いから自然にして」→ `/humanizer`

ポイント: 矢吹さんは**要点さえ伝えれば OK**。丁寧な言い回しは Claude と humanizer が担当する。

## 3. 返信テンプレ集（第 1 層・定型化できるもの）

> 【　】は新潟店で埋める欄。実際のコース名・料金・集合場所などは矢吹さんが入れてください。
> ここを僕（外部者）が想像で書くと事実とずれるので、あえて空けています。

### テンプレ ① コース内容の説明（一番多い）

聞き返し 4 点（人数・経験本数・ブランク・レンタル）を必ず入れる形。

```
[お客様の宛名] 様

この度はお問い合わせいただき、ありがとうございます。
Diving Service Freeway の矢吹と申します。

ご希望のコースについてご案内いたします。

【コース名】
・内容: 【コース内容をここに】
・所要時間: 【　】
・料金: 【　】円（税込）
・含まれるもの: 【器材レンタル / 保険 / など】

より正確にご案内するため、以下を教えていただけますでしょうか。

・ご参加人数: 何名様でしょうか
・ダイビングのご経験: これまで何本ほど潜られていますか
・前回潜られた時期: 直近のダイビングはいつ頃でしょうか
・器材レンタル: ご自身の器材をお持ちですか、レンタルをご希望ですか

ご返信いただければ、空き状況とあわせて詳しくご案内いたします。
どうぞよろしくお願いいたします。

Diving Service Freeway
【店舗名・電話・メール】
```

### テンプレ ② 予約問い合わせ（空き確認）への受付

```
[お客様の宛名] 様

お問い合わせありがとうございます。
ご希望の【日付】について確認いたします。

恐れ入りますが、ご案内にあたり以下を教えてください。

・ご参加人数
・ダイビングのご経験（本数）
・前回潜られた時期（ブランク確認のため）
・器材レンタルの有無

いただいた内容をもとに、開催可否と空き状況をご返信いたします。
よろしくお願いいたします。
```

> メモ: 空きの数だけでは予約可否を即答できない（お客様のレベル・コースで変わる）。
> このテンプレは「受付して聞き返す」までで、可否の判断は人がやる。

### テンプレ ③ 初心者の不安系（泳げない・はじめて）

矢吹さんの実際の説明をベースにしています。

```
[お客様の宛名] 様

お問い合わせありがとうございます。はじめての方も多くいらっしゃるので、
どうぞご安心ください。

足が届く浅いところから、ゆっくり始めていきます。
まずは呼吸の練習からスタートするので、泳ぎが得意でない方でも大丈夫です。

ご不安な点があれば、何でも遠慮なくお聞きください。
当日はスタッフがそばでサポートいたします。
```

### テンプレ ④ 悪天候による中止連絡（一番気を遣う）

これは矢吹さんが実際に使っている文面です。**まず原文を正本として残します**。

**矢吹さんの実物（原文）:**
```
ご予約いただいたダイビングの予約ですが、天候の方が悪くなってしまい、
開催することができません。大変申し訳ありません。
別の日程で再度日程を調整したいと思います。
```

**少し整えた版（humanizer のイメージ・好みで選んでください）:**
```
[お客様の宛名] 様

いつもありがとうございます。Freeway の矢吹です。

【日付】にご予約いただいておりましたダイビングですが、
当日の天候・海況が悪化する見込みのため、誠に申し訳ございませんが
中止とさせていただきます。

楽しみにしていただいていたところ、ご期待に添えず申し訳ありません。
あらためて別日での日程を調整させていただきたく、ご都合のよい候補日を
いくつか教えていただけますでしょうか。

何卒よろしくお願いいたします。
```

> どちらが良いかは矢吹さんの感覚で。原文のシンプルさが好きならそのままで十分です。
> 「整えた版」は語彙を足しただけなので、硬すぎると感じたら `/humanizer` で柔らかくできます。

## 4. トーンの使い分け（新規 と 常連）

矢吹さんの「新規は丁寧、常連はフレンドリー」をルール化したもの。

| 相手 | トーン | 具体 |
|---|---|---|
| 新規のお客様 | 丁寧 | 「いたします」「お願いいたします」。自己紹介を入れる |
| 常連のお客様 | フレンドリー | 「お久しぶりです」「また潜りに来てくださって嬉しいです」。前回の話に触れる |

Claude に頼むとき:
- 「新規のお客様なので**丁寧め**に」
- 「常連の〇〇さんなので**フレンドリーに**、前回〇〇を見た話に触れて」

> 常連さんの「前回〇〇を見て喜んでいた」などの記憶は、本来お客様カルテに貯めると
> 返信がさらに楽になります（`docs/04_skill_ideas.md` 候補 3 と連携）。

## 5. インバウンド（外国のお客様）

実態: あまり来ない。来たら翻訳しながら返している。

おすすめの流れ:
- お客様の外国語メールを Claude に貼る → 日本語で要約してもらう
- 返したい内容を日本語で伝える → 英語（または繁体字）の返信下書きを作ってもらう
- **送信前に必ず人が確認**（文化的なニュアンス・固有名詞のチェック）

頻度が低いので、テンプレを作り込むより「来たらその都度 Claude に翻訳してもらう」で十分。

## 6. これから貯めていくこと（暗黙知の第 2 層）

第 1 層（テンプレ）は今すぐ効きます。次は、定型化できない「お客様ごとの判断」を貯めます。

貯めると効くもの:
- よく聞かれる質問と、矢吹さんの「いつもの答え方」（FAQ として追記）
- 常連さんごとの好み・前回の話（→ お客様カルテに紐づける）
- 「この返し方で喜ばれた / 失敗した」エピソード（出てきたらここに 1 行ずつ追記）
- コース別の説明文の決定版（テンプレ ① の【　】が埋まったもの）

追記のしかた:
- このファイルを開いて直接書き足す
- または Claude に「メール返信プレイブックに〇〇を追記して」と言うだけ

---

## 7. 守ること（おさらい）

- 送信は人がやる。AI は下書きまで
- お客様の実名・電話・メールアドレスは消してから Claude に渡す
- コース内容・料金・空き可否など「事実」は矢吹さんが確認して入れる（AI に推測させない）
- 既存の Outlook 運用はそのまま。これは「書く部分を楽にする」だけ
