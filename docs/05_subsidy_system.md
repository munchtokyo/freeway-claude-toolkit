# 助成金システム (人材開発支援助成金) の詳細

> ⚠️ このドキュメントは**川島の推測・解釈**による叩き台です。リタクラウドからの公式回答 (グループ LINE 履歴 / 5/12 議事録 / 5/14 Q&A) を整理したものですが、最終的な判断はリタクラウドの中村様・狩谷様にご確認ください。

---

## 1. 制度の正式名称

**人材開発支援助成金 / 事業展開等リスキリング支援コース** (厚生労働省所管)

中小企業向けの助成率優遇枠を使う。

---

## 2. 助成額 (Freeway ケース・3 名・22h)

| 項目 | 条件 | 計算 | 金額 |
|---|---|---|---|
| 経費助成 | 中小企業 75% (上限 30 万円/人) | 受講料 383,333 円/人 × 75% | **287,499 円/人** |
| 賃金助成 | 1 人 1 時間あたり 1,000 円 | OFF-JT 22h × 1,000 円 × 3 名 | **66,000 円**(総額) |
| **合計** | | 287,499 × 3 + 66,000 | **928,497 円** |

リタクラウド申請代行手数料: 1 回目 10% + 2 回目 10%

## 3. 重要ルール (絶対遵守)

### 3.1 不正受給は絶対 NG

不正発覚時のリスク:
- 事業主名公表 + 関与代理人公表
- 返還 + 2 割加算
- 延滞金
- **5 年間不支給**
- 詐欺罪リスク

禁止行為:
- 現金キャッシュバック
- バーター取引・名目的値引き
- 参加者水増し・無償受講者の混入
- 実態と乖離した記載 (計画届と異なる実施内容・時間・場所)

→ DBA Japan は事業主との間で**覚書を電子契約書に明記**して実施。

### 3.2 OFF-JT のみ対象

- 業務代行・本番処理は**不可**
- 講師による本番予約処理・本番顧客対応・本番システム納品は**行わない**
- 演習はすべて**匿名化データまたは架空データ**を使用
- 成果物は受講者の技能習得の証跡 (本番システムそのものではない)

### 3.3 受講場所要件

- 対面: 9:00-13:00 (所定労働時間内)
- Zoom 同時双方向: 18:00-19:30 (所定労働時間外整合性は就業規則で確認)
- **Zoom 参加者は自席ではなく会議室等、執務に直接関係しない場所で受講必須**
- 新潟店参加 2 名 (安藤様・矢吹様) → **新潟店専用会議室の確保が条件**

### 3.4 時間・日程変更ルール

- 軽微 (30 分以内の時刻ずらし・録画モード変更): 講師事前連絡
- 中程度 (日付ずらし・形式変更): リタクラウド経由で変更届事前提出
- 重大 (受講者交代・全体再構成): 計画変更届の正式提出 (労働局審査あり)
- **計画書提出後の変更**: 変更後日程の**前日必着で変更届**、土日挟むと郵送間に合わない場合があるため**2 週間前まで**に連携

### 3.5 支払いルール

- 研修終了後**2 か月以内に支給申請**
- 支給申請**前日までに支払完了必須**
- 遅くとも研修終了**1 か月後までに支払完了**を推奨
- 分割払い可 (要計画的支払い)

### 3.6 設備投資加算は事実上断念

- 中村様 5/13 確認: 有料版 AI プログラム等を厚労省は対象として想定していない
- OJT と切り分けが必要で認定ハードル高
- v3.5 の「適用範囲を労働局確認中」は実質ネガティブ確定

## 4. 申請主体・名義

- 申請主体: **フリーウェイ法人**
- 講師事業者: DBA Japan (個人事業主 → 5/26 法人登記完了予定)
- **5 月中は個人事業主として申請可**。法人化後に労働局へ**変更届**提出で OK
