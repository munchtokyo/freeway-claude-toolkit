# 顧客情報を守る 5 箇条

ダイビングサービス事業者として、お客様の個人情報を AI ツールと一緒に扱うときに必ず守ってほしい原則。

---

## 1 箇条: 同意なき顧客個人情報を外部に送らない

Claude Code は Anthropic 社のクラウドと通信して動きます。お客様の個人情報（氏名・連絡先・住所・健康情報など）を AI に渡すときは、利用規約に同意した範囲内かを確認してください。

**目安**:
- ✅ 業務効率化のためにスプレッドシート内の情報を AI に処理させる: OK（業務委託の範囲内）
- ❌ お客様の名前と健康情報を AI に渡して外部のサービス（ChatGPT、Gemini等）に投稿する: NG（同意なしで第三者提供）

---

## 2 箇条: 健康情報・要配慮個人情報は別管理

ダイビング業界では既往歴・アレルギー・服薬情報など、**要配慮個人情報**を扱うことがあります。これらは普通の連絡先より厳しい扱いが必要です。

**運用ルール**:
- 健康関連の情報をカルテに書く時は、別シート（健康情報シート）に分けてアクセス制御
- 「アレルギーあり」など最低限の事実は通常カルテに、詳細は別シートに
- 外部 AI への投入は最小限に

---

## 3 箇条: 自動送信は禁止

Claude Code は便利ですが、**メール・LINE・電話メモ、すべて下書きまで**にしてください。送信ボタンは必ず人間が押す。

理由:
- 誤送信は信頼を一発で失う
- AI の判断ミスがそのままお客様に届くと取り返しがつかない
- 助成金研修中は「AI による業務代行」は不可

---

## 4 箇条: スクリーンショット・ファイルの場所に注意

Claude Code はあなたの PC のファイルを読めます。**お客様の個人情報を含むファイル**を以下の場所に置かないでください:

- ❌ Desktop の見える場所
- ❌ Downloads フォルダの放置
- ❌ Git リポジトリの中（コミットすると GitHub に上がる）

**推奨**:
- ✅ 専用フォルダ（例: `~/Documents/Freeway/customers/`）に集約
- ✅ クラウド同期は Google Drive の業務アカウントだけ
- ✅ Git リポジトリには **必ず `.gitignore`** で除外（このリポでは既に設定済み）

---

## 5 箇条: 「壊れた時の戻り先」を必ず持つ

AI ツールは便利ですが、たまに壊れます。お客様情報がアクセスできなくなると業務が止まります。

**運用ルール**:
- ✅ 既存の Excel 月別ファイル・じゃらん管理画面は**生かしたまま**残す
- ✅ Claude Code が動かなくなっても、既存運用でお客様対応ができる状態を維持
- ✅ Google スプレッドシートも定期的に Excel エクスポートしてバックアップ
- ✅ 「壊れた・分からない時の手順書」を 1 枚プリントして店舗に貼っておく

---

## 補足: 法的根拠

- 個人情報保護法（2022 年改正）
- 個人情報保護委員会 通則ガイドライン: https://www.ppc.go.jp/personalinfo/legal/guidelines_tsusoku/
- Q&A: https://www.ppc.go.jp/personalinfo/faq/APPI_QA/

詳細は社内の個人情報取扱規程を整備するのが望ましいですが、まずはこの 5 箇条を守るところから。
