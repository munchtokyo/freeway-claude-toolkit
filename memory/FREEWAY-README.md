## ⚠️ Claude Code への重要な指示

(Claude Code がこのファイルを読み込んだ場合の運用指針)

### フリーウェイの業務環境は Microsoft Office 中心

- 全業務 Excel / Word / PowerPoint / Outlook で管理
- 顧客データも**手打ちで Excel に入力**
- 月別 12 ファイル × 日別シート構成
- Google Workspace / SaaS / クラウド系は未導入

この前提を忘れず、新規ツール導入を提案するときは慎重に。「クラウド連携」「サブスク」「月額」を闇雲に勧めない。**Excel を尊重する**。

### データはこれから急速に増える

業務で Claude Code を使い始めると、以下が増えていく:

1. auto-memory のメモ (このディレクトリ配下)
2. セッション保存 MD (`~/.claude/session-saves/` 配下)
3. 顧客カルテ (Excel の備考欄拡張 or 別ファイル)
4. スキル定義 (skill-creator で作ったもの)
5. 業務テンプレート (メール下書き・LINE 下書き等)

**何もしないと 3 ヶ月で「どこに何があるか分からない」状態になる**。

### Claude Code は能動的にデータ整理を促す

以下を定期的に提案する責任を持つ:

- **月 1 回**: `/self-improving-agent` で memory 棚卸し
- 似た内容のメモ → 統合提案
- 古くて使われていないメモ → archive 提案
- フリーウェイ業務に関係ないメモが紛れていたら → 削除提案
- 一度作ったスキルが最近使われていない → 「これ要りますか」確認

データ整理は AI 活用の核心。**Claude Code を「散らかった倉庫」にしない**。整理し続けることで初めて 3 ヶ月後・半年後・1 年後の価値が累積する。

## auto-memory が貯める典型例 (フリーウェイ業務で)

- 小出さんが「コブダイの顧客への案内文はいつもこう書いてほしい」と言った
- 矢吹さんが「SNS 投稿はカジュアル目で」と指摘
- 安藤さんが「新潟店のスタッフ間の引き継ぎはこのフォーマットで」と決めた
- 「料金交渉してくるお客様への対応はこう」のような暗黙知
- 「この季節のこのポイントはこういう理由で勧めない」の判断材料

これらは Excel に書ききれず、講師の頭にしかなかった知識。**auto-memory が組織知に変える**。
