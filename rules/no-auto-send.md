# 自動送信禁止ルール (Freeway 専用・絶対ルール)

このリポで Claude Code が動く時、以下の操作は**絶対に自動実行しない**。下書き作成までで停止し、人間の最終確認を待つ。

## 禁止する自動操作

| 操作 | 理由 |
|---|---|
| メール送信 (`smtplib` / Gmail API / Outlook COM 等) | 誤送信は信頼を一発で失う |
| LINE メッセージ送信 (LINE Messaging API / LINE Notify 等) | 顧客個人 LINE への誤爆リスク |
| SMS 送信 (Twilio 等) | 同上 |
| 電話発信 (Twilio Voice 等) | 同上 |
| 予約自動受付 (空き状況から自動 OK 返信) | 空きだけで受諾可否は判断できない (小出さん明示) |
| 外部 API への顧客個人情報 POST | 第三者提供 |

## ドラフト出力は OK

| 操作 | OK |
|---|---|
| Outlook 下書きフォルダへの保存 (送信ボタン押さない) | ✓ |
| `drafts/email_yyyymmdd.md` への書き出し | ✓ |
| LINE 送信用文面の `drafts/line_yyyymmdd.md` への書き出し | ✓ |
| 電話原稿の表示 | ✓ |

## 例外運用 (個別承認必須)

「下書きを Outlook 下書きフォルダに入れる」以上の操作（直接送信・自動承認設定等）が必要になった場合、ユーザーに明示確認を取ってから実行。デフォルトは禁止。
