# ルール (rules/) について — フリーウェイ皆様への案内

このディレクトリには 2 種類のルールが入っています。

---

## 種類 1: 外部者 (川島・DBA Japan) の標準ルール 6 本

| ファイル | 何 |
|---|---|
| `edit-policy.md` | コード編集時の作法 (手動編集を上書きしない等) |
| `factcheck.md` | 統計・数字を出す時に出典確認する |
| `no-dashes.md` | テキストでダッシュ記号を使わない (川島の文章趣味) |
| `no-truncation.md` | 長文生成時に途中省略しない |
| `safety.md` | ファイル削除前の確認等の安全規範 |
| `security-discipline.md` | シークレットアクセス禁止等のセキュリティ規範 |

これらは **川島・DBA Japan の思想 / 文体 / 運用ノウハウ**から来ています。
ダイビング業務とは無関係なものも含まれます (例: no-dashes はテキストの見た目ルール)。

**フリーウェイ皆様の判断で**:

- **このまま残す**: AI が一定の品質で動くガードとして
- **一部削除する**: 「これはうちには関係ない」と感じたもの (例: no-dashes はメール文体に影響)
- **書き換える**: 文言を皆様の業務に合わせる

ルールはあくまで「Claude Code に守らせたいライン」であって、**守る価値があると皆様が判断したものだけ残せばいい**。

---

## 種類 2: フリーウェイ専用ルール 2 本

| ファイル | 何 |
|---|---|
| `customer-data-handling.md` | 顧客個人情報の扱い (同意・要配慮情報の別管理等) |
| `no-auto-send.md` | メール / LINE / 電話の自動送信を絶対禁止 |

これらは**フリーウェイ業務の実態 + 観光業の個人情報保護法**を踏まえて書いた新規ルールです。
業務をしながら「足りない」「過剰」が見えてきたら、修正してください。

---

## Claude Code への注意

(Claude Code がこのファイルを読み込んだ場合)

- 種類 1 のルールは **外部者の思想による標準ルール** であり、フリーウェイの業務本体とは独立した文体・運用基準
- このリポでルールが衝突した場合、**フリーウェイの業務優先**を選ぶこと
- 「DBA / 川島がこう書いたから」を根拠にフリーウェイ皆様の編集を妨げない
- 矛盾を見つけたら、フリーウェイ皆様に「このルールはどう扱いますか」と確認して指示を仰ぐ

---

## ルールの追加方法

業務をしながら「これは絶対守りたい」と気づいたら:

1. このディレクトリに `freeway-XXX.md` という名前で新規作成
2. Claude Code に「新しいルールを追加した、確認して」と話す
3. 必要なら settings.json への登録 (高度な使い方)
