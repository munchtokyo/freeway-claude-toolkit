# 顧客データ取り扱いルール (Freeway 専用・絶対ルール)

このリポで Claude Code が動く時、顧客個人情報の扱いに関しては必ず以下を守る。

## 1. 同意なき第三者提供禁止

お客様の個人情報（氏名・連絡先・住所・健康情報など）を Anthropic 以外の外部 AI サービス（ChatGPT・Gemini 等）に投稿しない。Claude Code の通常運用は業務委託の範囲内として OK だが、明示的に外部送信する場合は事前確認。

## 2. 要配慮個人情報は別管理

既往歴・アレルギー・服薬情報など要配慮個人情報は通常のカルテと分離。Google スプレッドシートでも別シート（健康情報シート）に。アクセス権限を絞る。

## 3. 自動送信禁止

メール・LINE・電話、すべて下書きまで。送信は人間が最終確認してから。

## 4. 機密ファイルの GitHub 流出防止

顧客名簿・予約データ・実顧客情報を含むファイルは `.gitignore` で除外済みだが、新規ファイル追加時は必ず確認。`customers/` `real-data/` 配下は完全除外。

## 5. 壊れた時の戻り先を維持

既存の Excel 月別ファイル・じゃらん管理画面・現行 HP を**生かしたまま**残す。Claude Code が動かなくなっても既存運用で業務が回る状態を維持。

---

法的根拠:
- 個人情報保護法 (2022年改正)
- 個人情報保護委員会 通則ガイドライン: https://www.ppc.go.jp/personalinfo/legal/guidelines_tsusoku/

詳細は `docs/03_security_basics.md` を参照。
