# karte — 顧客カルテ・暗黙知蓄積

## 目的

これがこのパッケージの本丸。

ダイビング業務で最も価値のある資産は、お客様一人ひとりの「過去の挙動・好み・講師との相性・健康状態」という暗黙知。これは Excel に書ききれない自由記述で、講師の頭の中にしか存在しない。

**講師複数いる場合の引き継ぎコストがゼロになる**。
**5 年経って累積したカルテから「この層のお客さんはこのポイントが刺さる」のパターン抽出も可能になる**。

---

## 入力経路（個人が選べる）

### A. 音声口述（推奨・両手が汚れててもできる）

ダイビング終了後の片付けながら、Claude Code を起動して話しかける:

```
/karte 田中太郎さん の今日の様子を記録する
```

そのまま音声で:

> 「初日緊張してたけどコブダイ見た瞬間目の色変わってた。
>  中性浮力はまだ不安定。安藤さんと相性良かった。
>  次回もコブダイ系のポイント連れてきたい」

→ Claude が文字起こし + 構造化 + 顧客マスター追記。

### B. チャットスタイル（テキスト派）

```
/karte 田中太郎
- 緊張型・コブダイで覚醒
- 中性浮力未安定
- 講師相性: 安藤◎
- 次回提案: コブダイ系ポイント
```

### C. 過去カルテの呼び出し

```
/karte 田中太郎さんの過去履歴
```

→ 顧客マスターのカルテ列を読んで要約してくれる。

```
/karte 来週来るお客様の事前ブリーフィング
```

→ 翌週予約のお客様全員のカルテ要点を一括出力。

## 蓄積項目（顧客マスターのカルテ列）

### 基本情報

- リピート回数
- 前回来店日
- 過去のコース履歴
- ライセンス
- 体型・スーツサイズ・ブーツサイズ
- ブランク傾向

### 技術・挙動

- 中性浮力の癖
- 耳抜き能力
- ダウン速度
- パニック傾向
- 攻め型 / 慎重型
- 船酔い耐性
- 海況耐性

### 趣味嗜好

- 見たい生物（コブダイ / マンタ / 群れ等）
- 写真撮りたがる度合い
- 沈船派 / 地形派 / 生物派
- 過去刺さったポイント

### 講師相性

- 同行講師履歴
- 「この講師と合った」記録
- 「この講師と合わなかった」記録
- 避けたい組み合わせ

### 同行情報

- 家族 / カップル / 友人 / 一人参加
- 同行者の名前と関係

### 滞在情報

- 宿泊先
- 滞在日数
- 移動手段
- リピート間隔

### 当日テンション・反応

- 楽しんでた / 物足りなさそう
- 「次回○○行きたい」と言ってた
- 不満点（あれば素直に記録）

### 健康・配慮事項（要配慮個人情報）

⚠️ **これは別シート（健康情報シート）で管理**。アクセス制御を別途。

- 既往歴
- アレルギー
- 服薬
- 健康診断書の提出履歴

## 検索・参照パターン

```
/karte 体重 70-80kg の男性で過去にコブダイ見て感動した人を全部
```

→ 蓄積データから条件検索。チーム分け検討の判断材料に。

```
/karte この層のお客さんが刺さりやすいポイントを分析して
```

→ 過去 5 年分のカルテからパターン抽出（Claude の解析力を活用）。

---

## 重要原則

### 1. 健康情報は別シート

要配慮個人情報は通常カルテとは別管理。アクセス権限も絞る。

### 2. 主観的な書き方 OK

「なんとなく緊張してた」「あの講師と妙に話が合ってた」など、定量化できない感覚も全部書く。それが暗黙知の価値。

### 3. ネガティブな情報も書く

「クレーム傾向あり」「料金交渉してきた」など、ネガティブな情報も率直に。**講師全員で共有することで対応の質が上がる**。
ただし**お客様に直接見せない**前提（社内資産）。

### 4. 当日に書く

記憶は翌日には半分以下。**ダイビング終了後 1 時間以内**に書くのが理想。
夕方の片付けながら音声口述が最適。

### 5. 講師全員が書ける状態に

小出 / 安藤 / 矢吹 全員が書ける。書いた人の名前（誰が書いたか）を記録列に残す。

## 既存運用との関係

現在の暗黙知:
- 講師の頭の中
- 個人 LINE のやりとり
- 一部 Excel 備考欄

これらを **Google スプレッドシート顧客マスターのカルテ列に集約**していく。
ただし**置き換えない**。既存運用は生かしたまま、カルテは「補完資産」として育てる。
