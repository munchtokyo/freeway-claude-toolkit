# kyugyo-calendar — 休業日カレンダー反映

## 目的

小出さんから明示的に「休業日をカレンダーに載せたい」と要望あり (2026-05-14)。

休業日カレンダーは:
- スタッフ全員の予定共有
- HP の「本日の海況」ページとの連動候補
- 予約受付時の自動チェック（その日は休みです、と返せる）

の基盤になる。

---

## 入力パターン

### A. 単一日

```
/kyugyo-calendar
6/15 は休業日として登録して
```

### B. 期間一括

```
/kyugyo-calendar
8/1 から 8/15 まで毎日休業日として登録して
```

### C. パターン登録

```
/kyugyo-calendar
毎週水曜日を年内ずっと休業日として登録して
```

---

## 出力

Google Calendar に「Freeway 休業日」カレンダーを作成し、イベントを追加する。
イベントは終日扱い、表示「忙しい」で。

---

## 重要原則

### 1. 既存予約との競合チェック

休業日に既に予約が入っている場合、登録前に警告。
人間判断で対応（予約優先 or 休業優先）。

### 2. 共有設定

スタッフ全員（小出・安藤・矢吹・他講師）にカレンダー共有。
読み取り権限はスタッフ全員、書き込み権限は小出さん・安藤さん。
