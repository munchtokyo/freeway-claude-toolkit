# kizai-match — 器材マッチング簡易版

## 目的

業務 ③ 器材準備（1 日 1-2 時間）の負担軽減。
顧客の体型からスーツ・ブーツ・フィンのサイズ候補を提案する。

現状の痛み:
- お客様の体型に合ったスーツを探すのが面倒
- 試着しないとフィットが分からないが、最初の候補出しが手間
- 在庫管理との突き合わせ

---

## 入力パターン

```
/kizai-match
明日来る田中太郎さん、男性・身長170・体重65。スーツとブーツのサイズ候補は？
```

→ Claude が:
1. 顧客マスターで田中さんの過去履歴を検索
2. 過去履歴があればそれを優先
3. なければ体型から M/L/XL の候補を出す
4. ブーツ・フィンの目安サイズも提示

---

## 出力例

```
田中太郎さん の器材候補:

【スーツ】
- 過去履歴: 2025-07 に M を着用、フィット良好（記録あり）
- 推奨: M

【ブーツ】
- 過去履歴なし
- 身長170/体重65 から推測: 26-27cm

【フィン】
- 過去履歴なし
- 推奨: M-L サイズ

⚠️ 最終決定は試着後に判断してください。
```

## 重要原則

### 1. 試着が最終判断

AI は候補を出すだけ。試着しないと本当のフィットは分からない。

### 2. 「合わなかった」記録を積む

「M を試したけど太ももキツくて L にした」のような調整記録を顧客マスターに残す。
次回提案の精度が上がる。

### 3. 在庫管理は別

このスキルはサイズ候補出しまで。在庫があるかは Excel 在庫表で別途確認。
